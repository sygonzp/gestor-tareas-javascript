# 📚 Gestor de Tareas Académicas - UANL

Aplicación web interactiva del lado del cliente desarrollada para la **Actividad 3** del Laboratorio de Programación Web. Esta herramienta permite administrar, registrar y conservar información de tareas y proyectos escolares sin depender de un servidor externo.

## 🚀 Características Principales

El proyecto cumple con los requerimientos de la rúbrica evaluativa mediante las siguientes implementaciones:

* **Manipulación del DOM:** Actualización de la interfaz (agregar, visualizar, tachar y eliminar tareas) en tiempo real sin recargar la página.
* **Persistencia de Datos:** Uso de `localStorage` para guardar y recuperar la información entre sesiones del navegador.
* **JavaScript Moderno (ES6+):** Utilización de `let/const`, Arrow Functions (`=>`), Template Literals y métodos modernos de arreglos como `.map()`, `.filter()` y `.forEach()`.
* **Validación de Datos:** Prevención de registros vacíos con mensajes de error visuales mostrados al usuario antes de insertar en el DOM.
* **Funciones Adicionales:** 
  * **Filtro dinámico:** Permite visualizar tareas por categoría (Todas, Pendientes, Completadas).
  * **Contador automático:** Muestra en tiempo real la cantidad de tareas visibles según el filtro seleccionado.

## 🛠️ Tecnologías Utilizadas

* HTML5 (Estructura semántica)
* CSS3 (Diseño responsivo y UI)
* JavaScript ES6+ (Lógica de la aplicación y eventos)

## 💻 Instalación y Uso

1. Clona este repositorio o descarga los archivos.
2. Abre el archivo `index.html` en cualquier navegador web moderno (Chrome, Edge, Firefox).
3. Escribe una tarea en el campo de texto (ej. "PIA de Ventas") y presiona el botón **Agregar**.
4. Utiliza el botón verde (✔) para marcar una tarea como completada y el botón rojo (✖) para eliminarla.
5. Usa el menú desplegable superior para filtrar tu lista.
